# INPSan Official Checkpoint — CP-SEC-002

**Title:** AuthN/RBAC/Scope/Audit Integration — Control Plane v0.2.2-dev  
**Recorded:** 2026-09-28  
**Parent:** CP-3.3-FINAL-001  
**Status:** IMPLEMENTATION CHECKPOINT — S2 PARTIAL / S3 STARTED

## 1. Scope of this checkpoint

This checkpoint records the first integrated security-control implementation line in INPSan 3.3:

- independent named identity/authentication;
- capability-based RBAC;
- explicit endpoint-permission registry;
- explicit object/scope authorization engine;
- canonical security audit module;
- integrated Control Plane v0.2.2-dev;
- static verification contract.

## 2. Implemented artifacts

### Identity/AuthN
- `src/control-plane/lib/INPSan/Security/Auth.pm`
- named local identities;
- password verifier with per-user salt;
- session issuance/validation/revocation;
- idle/absolute lifetime fields;
- explicit scope grants carried in identity/session.

### RBAC
- `src/control-plane/lib/INPSan/Security/RBAC.pm`
- deny-by-default;
- capability-based role mappings;
- roles are not hard-coded authorization decisions;
- authorization result includes reason.

### Endpoint Policy
- `src/control-plane/lib/INPSan/Security/EndpointPolicy.pm`
- central endpoint -> permission mapping;
- method-aware policy;
- unregistered protected endpoints are denied.

### Object Scope
- `src/control-plane/lib/INPSan/Security/Scope.pm`
- exact resource-scope validation/matching;
- initial canonical scope types:
  node, pool, dataset, lun, share, site;
- no wildcard/inheritance before Central Manager scope model is defined.

### Security Audit
- `src/control-plane/lib/INPSan/Security/Audit.pm`
- canonical JSONL event schema;
- actor/action/target/permission/outcome/reason/product-version fields;
- explicit rejection of obvious secret-bearing audit fields;
- restrictive file creation;
- development-only evidence path.

### Integrated Control Plane
- `src/control-plane/inpsan-control-plane-v0.2.2-dev.pl`
- loopback-only development binding;
- authenticated read endpoints;
- endpoint-policy lookup;
- capability authorization;
- security audit for authentication/authorization events;
- no storage state-changing endpoint.

### Verification
- `src/control-plane/verify-security-v0.2.2.sh`
- syntax/dependency checks;
- RBAC positive/negative semantics;
- endpoint policy checks;
- scope positive/negative checks;
- audit schema test;
- wiring checks.
